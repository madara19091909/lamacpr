LAMMA - Firebase setup checklist

Android application ID: com.lamma.social
Flutter package name: lamma

1. Create a Firebase project named LAMMA in Firebase Console.
2. Add an Android app with package name com.lamma.social.
3. Add the SHA-1 and SHA-256 signing fingerprints for the Android build used for Google Sign-In.
4. Enable Google as a provider in Firebase Authentication.
5. Create a Cloud Firestore database in production mode.
6. Create a Firebase Storage bucket.
7. From a machine with Flutter and Dart installed, install FlutterFire CLI and run:
   dart pub global activate flutterfire_cli
   flutterfire configure
8. Keep the generated lib/firebase_options.dart file in the project.
9. Update lib/core/services/firebase_bootstrap.dart to import firebase_options.dart
   and initialize with:
   await Firebase.initializeApp(
     options: DefaultFirebaseOptions.currentPlatform,
   );
10. Deploy firestore.rules and storage.rules after reviewing them.
11. Do not publish service account private keys or admin SDK credentials in the app.

Important:
- The starter source currently compiles without firebase_options.dart, but Firebase is
  not connected until the configuration above is completed.
- Never put Firebase Admin SDK credentials in Flutter or in the APK.
- Review and tighten the rules before inviting real users. These are an initial
  foundation, not a complete production security policy.
